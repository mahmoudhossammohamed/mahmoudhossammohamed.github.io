## Before publishing

1. Open `index.html`.
2. Replace the placeholder WhatsApp number `201000000000` with your real number.
3. Add real project screenshots inside `assets/`.
4. Update project cards with your screenshots if desired.

## GitHub Pages

Create a repository named:

`mahmoudhossammohamed.github.io`

Upload the contents of this folder, then go to:

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

Your site will be:

`https://mahmoudhossammohamed.github.io`
